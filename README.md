# 一拍即合（ShutterMatch）· 产品经理项目作品集

摄影师双边撮合平台 · 产品经理项目作品

## 这是什么

「摄影师接单赚钱 × 用户找摄影师」的双边撮合交易平台，本仓库是该项目产品经理作品的线上展示。

## 文件说明（全部放在仓库根目录即可）

| 文件 | 内容 |
|---|---|
| `index.html` | 作品集入口页（聚合项目文档 / 竞品分析 / 产品原型 / 需求文档四个入口 + 二维码） |
| `qr.png` | 作品集入口页二维码 |
| `一拍即合App原型.html` | 12 屏可交互产品原型（用户端 / 摄影师端） |
| `portrait1~4.jpg`、`travel1~3.jpg` | 原型所需的 7 张配图 |
| 两份 Word 文档 | 项目流程文档、产品需求文档（PRD） |

> 注意：所有 HTML 里的图片都引用**根目录**文件（无 `assets/` 子文件夹），所以这些文件必须全部平铺放在仓库根目录，页面图片才能正常显示。

## 上传方法（不用建文件夹）

1. 打开仓库上传页：`https://github.com/lisiyu1824/seeyou/upload`
2. 把**这个文件夹里的全部文件**一起拖进去（或逐个拖都行，都在根目录）
3. 若提示文件已存在，勾选「覆盖 / Replace」或直接 Commit
4. GitHub Pages 会自动重新构建，等 1–2 分钟刷新即可
